# 方法来源与适用边界

本技能将简历写作方法中的个人综述、结构化经历及篇幅取舍，转化为有适用边界的编辑流程。以下说明区分可以采用的方法和需要按情境判断的建议。示例用于说明写法，不代表任何使用者的真实经历。

## 采用的方法

- 让读者迅速识别核心优势，在联系方式后前置简短个人综述。
- 从岗位需求筛选有证据的卖点，避免空泛自评。
- 每段经历先给概述，再按问题、目标、行动和结果展开，减少职责流水账。
- 不为了固定一页而牺牲关键经历和可读性，减少无关内容与重复陈述。

## 转换为条件性判断的建议

| 讲稿观点 | 本技能的处理 |
| --- | --- |
| 每人必须写三条综述 | 有价值时前置约 2–3 条；内容少时不凑数 |
| 求职意向、课程、技能模块都删除 | 根据岗位、资历、投递方式和用户要求取舍 |
| 必须有照片，不放照片影响外貌判断 | 照片由地区、岗位要求和用户选择决定，不作外貌判断 |
| 公司或学校本身证明能力 | 将其作为真实背景，能力结论由贡献和成果支持 |
| 日期必须写在右边 | 突出组织与角色，同时保持日期易读和解析顺序清楚 |
| 办公技能已被 AI 取代，应改写 AI 工具 | 保留岗位需要且能证明的技能，不凭空加入 AI 能力 |
| 团队、导师或同事成果可算成个人成果 | 明确团队结果和个人负责范围；未参与的工作不归为个人贡献 |
| 修改后保证高分或获得面试 | 不做无依据评分和结果承诺 |

## 示例仅用于说明写法

已知素材：“参与访谈，整理反馈，制作需求清单。”

可写：“参与用户访谈并整理反馈，形成需求清单，为后续需求评审提供输入。”最后半句只有在实际用于评审时才能加入；用途未知时询问，不猜测。

不可直接写：“主导用户增长项目，将转化率提升 30%。”原素材没有负责人身份、增长目标和结果证据。

团队成果已确认、个人只负责访谈时，可写：“参与某项目，负责用户访谈及反馈整理；团队最终达成某项已确认结果。”仍需核对成果口径与项目关联。
