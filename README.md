# 简历修改skill

一个根据原简历与目标岗位 JD 修改中文或英文简历的可复用技能。显示名称为 **简历修改skill**，调用标识为 `resume-reviser`。

## 能做什么

- 提炼有事实支撑的个人综述，突出岗位匹配点。
- 将职责流水账改写为问题、目标、行动与成果。
- 区分个人贡献、团队成果和项目规划，保留数据口径与贡献边界。
- 将岗位关键词融入真实经历，不堆砌词语或编造技能。
- 根据招聘要求与内容密度调整篇幅，并检查文件版式。
- 输出完整修改稿、关键修改说明及必要的补充问题。

## 使用

本仓库本身是一个技能文件夹；在支持 `SKILL.md` 的环境中加载。文件夹名称使用 `resume-reviser`。

调用示例：

```text
使用 $resume-reviser，根据我的原简历和目标岗位 JD 优化简历，给出完整修改稿、关键修改说明和待补充问题，不编造经历或数据。
```

也可以指定编辑范围：

```text
使用 $resume-reviser，围绕岗位中的 AIGC、内容策划、数据复盘和跨团队协作要求改写简历。只使用我的材料支持的关键词，区分实际运营经验与尚未执行的方案。
```

```text
使用 $resume-reviser，将简历精简至一页，保留最相关的成果，优先删减重复内容，保证字号和阅读体验。
```

提供原简历；有具体岗位时一并提供 JD。缺少 JD 时可先优化通用版。直接编辑在线文档需要运行环境具备对应编辑工具和访问权限；本技能不附带账号、凭据或浏览器权限。

## 事实与隐私

不编造经历、数字、学校、职位或技能；不将团队成果直接归为个人贡献；不把未来目标写成已完成成果。本仓库只包含通用技能说明，不包含个人简历、联系方式、比赛计划书或编辑页面链接。

使用者应在投递前核对事实与数字。本技能不保证通过特定 ATS、获得面试或录用。
